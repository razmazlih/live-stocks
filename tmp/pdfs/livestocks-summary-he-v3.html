מה המערכת הזו

אפליקציית Portfolio Dashboard לניהול תיק מניות בזמן אמת עם אנליטיקה, Watchlist, חישובי PnL ומעקב רב-מסכים.

המוצר משלב ממשק משתמש עשיר, שכבת API פנימית, חיבור ל־Supabase, ושירותי שוק חיצוניים (Finnhub + שערי מטבע).

למי זה מיועד

  • משקיע פרטי שרוצה תמונת מצב מהירה ומדויקת של תיק ההשקעות.
  • משתמש שעובד בעברית או באנגלית וצריך מעבר שפה ותמיכה ב־RTL/LTR.
  • מי שמנהל פוזיציות, לוטים, ותוכניות יציאה ורוצה ניתוח ביצועים מתמשך.

מפת רכיבים ושירותים

רכיבי מערכת מרכזיים

  • app/: ניתוב ומסכים.
  • components/: UI reusable כולל chart cards.
  • hooks/: לוגיקת טעינה ותיאום state.
  • lib/: חישובים, תרגומים, שירותי API, context.
  • supabase/: סכמת DB, מיגרציות, seed ותצורה.

נתיבי API שזוהו

  • GET /api/quote
  • GET /api/candles
  • GET /api/exchange-rate
  • POST /api/portfolio
  • GET /api/portfolio/combined-pnl
איך מריצים מהר (Minimal)
1התקנת תלויות
npm install
2יצירת קובץ סביבה
cp .env.exemple .env.local
3הפעלת Supabase מקומי
npx supabase start
4מיגרציות ונתוני seed
npx supabase db reset
5הרצת אפליקציה
npm run dev
6בדיקות איכות
npm run lint && npm run typecheck && npm test
